## Open Source

### [FDA Toolkit](https://github.com/CoreInsightFinance/Financial-Data-Analysis-Toolkit-Workspace): finance data cleaning and validation in Python

[![PyPI version](https://img.shields.io/pypi/v/fda-toolkit.svg)](https://pypi.org/project/fda-toolkit/)
[![Python versions](https://img.shields.io/pypi/pyversions/fda-toolkit.svg)](https://pypi.org/project/fda-toolkit/)
[![License](https://img.shields.io/pypi/l/fda-toolkit.svg)](https://pypi.org/project/fda-toolkit/)
[![Downloads](https://img.shields.io/pypi/dm/fda-toolkit.svg)](https://pypi.org/project/fda-toolkit/)

I created and maintain **FDA Toolkit**, an open source Python package of 67 functions across 8 modules for cleaning, validating and preparing financial data. It replaces fragile spreadsheet steps with structured validation, transformation and reporting functions, so analysis is auditable and repeatable.

- Clean, standardise and validate financial datasets before reporting
- Support reconciliations, data quality checks and traceable workflows
- Apply audit logging and consistent error handling
- One line workflows such as `ftk.quick_clean_finance()`

```bash
pip install fda-toolkit
```
